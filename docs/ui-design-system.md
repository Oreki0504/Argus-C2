# ARGUS 界面设计规范

方向：**Argus Hybrid**。参考 [Vercel Geist](https://vercel.com/geist/introduction) 的字体、边界与视觉层级，以及 [IBM Carbon](https://carbondesignsystem.com/) 的布局和交互方式。使用本地 Geist 字体、语义 HTML、静态 CSS 和 Lucide 图标；不是官方组件库的直接实现。

## 品牌与顶栏

- 产品标识和浏览器标题统一使用 **ARGUS**。
- 匿名访问默认进入 User 界面；User 和 Admin 均无侧栏。Admin 顶栏保留 Overview／Traffic／管理入口及账户操作。
- 顶栏右侧依次放置语言圆形按钮、主题圆形按钮、灰色文字登录入口。登录入口无矩形描边。
- 圆形按钮直径 40px，具备明确的可访问名称、悬停提示和键盘焦点。登录操作触达高度至少 44px。
- 支持中文／英文和浅色／深色。只持久化 `argus.language` 与 `argus.theme`；首次主题遵循系统偏好。身份、令牌及观测数据不进入持久存储。

## Overview

- 英文状态筛选默认文字固定为 **All Server**；中文为“全部服务器”。
- 搜索框与五张状态筛选卡片处于同一行：All Server、Online、Stale、Offline、Never seen。卡片显示数量和选中状态，点击后更新服务器列表并重置分页。数量随名称搜索更新，不受当前选中状态影响；小屏缩短搜索框，筛选文字允许换行，控件仍保持同排。
- 卡片采用紧凑上下间距，仅展示名称、系统、状态及 CPU、内存、磁盘、下行、上行五项指标。五项横向排列，均包含数字和进度条；带宽补充实际速率。
- 不保留卡片底部的 Latest observations、Resources 时间行或 Details 操作行。整张卡片可点击，名称链接支持键盘操作。
- 过期数据保留简短状态提示；精确资源和流量时间可在详情页查看。缺测用“—”，不当作 0%；带宽百分比使用各方向配置容量。
- 卡片列数随可用内容宽度变化：小于 740px 为一列，740–1139px 为两列，1140px 起为三列。每页行数随窗口高度调整，最多四行；更多服务器通过分页访问，搜索或筛选后回到第一页。

## 优先同屏显示

- 常规桌面验收基线为 **1366×768、1440×900，100% 缩放**，包含开发预览条。Overview 当前页以及常规 Details 的核心信息应无需页面纵向滚动即可查看。
- Details 默认展示当前五项使用率、时间范围控制，以及三列两行的“五张历史曲线＋系统信息”。更高的窗口增加图表高度。
- 保留 1h／24h／7d、键盘滑块、指针采样和准确时间。完整采样表按需在对话框中打开，表格在对话框内滚动；Escape 关闭后焦点回到入口。
- 优先减少重复文案、空白和默认展开的长内容，不使用固定页面高度、隐藏页面溢出或缩小整个页面来伪造同屏效果。
- 较窄窗口下详情重排为两列／一列；移动端、浏览器放大、异常状态或较长内容允许自然滚动。可读性、完整信息和键盘访问优先于绝对不滚动。数据表允许横向滚动，页面本身不应横向溢出。

## 主题与可访问性

基础样式位于 `web/src/styles.css` 与 `web/src/viewer.css`；紧凑布局及主题覆盖位于 `web/src/appearance.css`。颜色使用 canvas、surface、subtle、text、muted、border、accent、focus 等语义变量；深色主题同时调整输入框、图表、状态、对话框和文字颜色。

状态必须包含文字，不能只依赖颜色。缺测区间不连接曲线、不补零。保持焦点可见、支持 reduced motion，并检查浅色／深色下的文字对比度。主题或语言切换应保留当前路由、筛选和键盘焦点。

验收包含桌面滚动尺寸、窄屏重排、分页、语言／主题持久化、对话框键盘操作以及 Axe 自动检查。当前预览使用模拟数据；后端状态见 [Web Console 状态](web-design.md)。

## 管理界面

Admin 顶栏的“管理”入口打开“任务／Agent／审计／用户与权限”横向标签。Overview 继续用于监控，Agent 管理展示真实主机名、接入状态和证书信息。入口和写操作仅对具备对应能力的 Admin 展示；Go 服务端独立校验当前角色和会话，写操作还在事务内复核授权。

| 页面       | 集中入口                               | 与对象关联的操作                                                                        |
| ---------- | -------------------------------------- | --------------------------------------------------------------------------------------- |
| 任务       | 查看任务列表、状态与结果，提供新建任务 | Agent 详情右上角“下发任务”，带入当前 Agent；使用已支持的诊断任务类型和对应参数表单      |
| Agent      | “添加 Agent”默认生成安装命令，可切换手动注册 | 禁用放在对应 Agent 的“更多”菜单，确认时明确显示目标及影响；不展示尚不存在的重新启用操作 |
| 审计       | 可筛选的操作记录列表                   | Agent／任务详情提供“相关审计”链接，并带入过滤条件                                       |
| 用户与权限 | 成员、角色与访问状态                   | 角色修改在成员行操作或编辑面板内完成，明确区分 User 与 Admin                            |

新建任务使用原生对话框，提交后打开任务详情。注册令牌、禁用和权限修改也使用独立对话框；审计与用户列表使用完整页面。长表格分页并限制内部滚动区域，表头固定，操作表单按需打开，保持 Overview 的紧凑布局。Escape 关闭后焦点回到入口；提交过程中防止重复操作。

安装对话框保持“安装命令／手动注册”两项横向选择。生成前展示系统要求、可用架构、目标 Fleet 和有效期；生成后展示 curl／wget 选择、只读命令与复制按钮。单个命令用于一台主机，过期清空、关闭即移除，不写入浏览器存储。无法使用剪贴板时选中文本供手动复制。1366×768 下弹窗完整展示；窄屏允许必要滚动。预览明确标注示例不可安装，真实服务器未配置安装包时展示原因并保留手动入口。

四个页面和 Go Console API 已实现。生产使用 OIDC、Cookie 会话与 CSRF，管理操作复用既有 Fleet 服务；预览模式仍使用独立模拟数据。任务仅支持六类固定诊断，不能执行任意命令。令牌仅展示一次，不进入浏览器持久存储；禁用要求输入 Agent ID；账户修改要求确认 OIDC Subject，提升 Admin 另需明确勾选。列表和任务详情提供手动刷新。部署与观测限制见 [Console 配置](console.md)。
